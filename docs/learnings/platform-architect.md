# Platform architect learnings

## Active
- [work] 2026-10-22 Since 2026-10-22, Studio is open by product decision (rev liveonair--0000016): no STUDIO_TOKEN env, no studio-token secret. deploy.ps1 still reads $env:STUDIO_TOKEN as a fallback, so a stale shell variable silently turns auth back on. Clear it before deploying unless that is the intent.
- [work] 2026-10-22 Order for toggling a Container Apps secret-backed env var. Off: remove the env var (new revision), then `secret remove` (app-level, no new revision). On: `secret set` first, then `--set-env-vars NAME=secretref:name`. Check that no live match is running first; a new revision restarts the in-process live state.
- [work] 2026-10-22 /api/health on image v0-15-0-6de35ce reports version 0.14.3. The image tag is the source of truth for what is deployed, not the version field. Fixed in v0.15.1 (rev liveonair--0000017), which reports 0.15.1.
- [mistake] 2026-10-22 ACR build on Windows crashes client-side with a cp1252 UnicodeEncodeError when vite prints a check mark, but the remote run keeps going. Don't resubmit. Poll "acr task list-runs --top 1" (with both scope flags) for status and outputImages. (Corrected 2026-10-23: setting PYTHONIOENCODING=utf-8 does NOT prevent the crash; the bundled Windows CLI writes through colorama/cp1252 regardless. Remote run takes about 2.5 min.) The permission guard also scans file-write commands, so write notes that mention CLI commands with the edit tool, not a shell here-string.
- [work] 2026-10-22 Tokenless post-deploy realism check: POST /api/live/start {generate:{scenario,seed},speed:60} plays 90 minutes in about 90 s. Then POST /mcp tools/call get_player_stats (stateless, no session); the rating is at players[].impact.rating. Event types come from GET /api/live/fixture.
- [mistake] 2026-10-23 "acr build" rejects a .tar.gz as its source ("should be a local directory path or remote URL"). Extract `git archive <sha>` into a clean temp dir and build from that. POST /mcp returns 406 unless the request sends Accept: application/json, text/event-stream.
- [work] 2026-10-23 The CLI log-analytics query has no --resource-group flag, so the permission guard blocks it. For post-deploy checks, use containerapp replica list (restartCount) and containerapp logs show with --revision (console only) or --type system --format json without --revision (system logs reject --revision/--replica/--container and only support json; filter on RevisionName client-side). Before deploying, check /api/live/status: a running match with fixtureId gen-late_winner-20261027 at speed 20 is the unattended demo watchdog and safe to interrupt.
- [mistake] 2026-10-23 During the v0.16.1 deploy, "containerapp update" crashed client-side on a transient DNS failure while polling, but the PATCH had already been accepted and rev liveonair--0000019 rolled out. If the CLI fails after submitting, check "containerapp revision list" (with both scope flags) before retrying. Measure the tracking-stream fps on a running match: near full time the stream drains and then sends "ended", which looks like a low frame rate.
